Findings that shape it:
- Every tab-resolving tool call funnels through `ControlService.perform`'s `default:` branch — gate, redaction, untrusted wrapping and audit live there once. `tabs_list` and `wait` bypass it and must be gated/scrubbed explicitly.

- `ControlTools.all` and `ControlCommand` are hotspots; P1 splits the tool list so later streams only append.

Pass: all green (+ manual Google Docs check later with user present). Fallback: DOM path stays, stage deleted, `click` reports `trusted:false`.

## Phase 2 — sensitive actions, handoff, dialogs, downloads (after P1; M)
Library `inspect(target)` before every acting call → facts (is submit, form has password/card/PII fields, button text pay/buy/order/subscribe/authorize/allow/delete, `download` attr, OAuth-like URL, login page, CAPTCHA iframe recaptcha/hcaptcha/turnstile) → policy ask/handoff. Typing into password fields always refused + handoff. Tool `request_user(reason)`: badge, returns when user presses Done or timeout. Agent-tab downloads await approval in `DownloadManager` `decideDestinationUsing`. `present()`: alert/confirm/prompt from agent-folder tabs → per-tab queue, no sheet; tool `dialog(action: accept|dismiss, text?)`; tool results mention an open dialog; 30 s timeout → dismiss. beforeunload: public WKWebView never shows "Leave site?" — navigation always proceeds; document, no force param.
Tests: headless `testPaymentSubmitAsks`, `testCaptchaHandsOff`; windowless `testInspectFlagsCardFormAndOAuthLink`; LunaTests `testAlertInAgentTabDoesNotSheetUserWindow`, `testAgentDownloadWaitsForApproval`.

## Phase 3 — trusted input + more actions (after P0 + P1; L)
`Features/Control/ControlStage.swift`: one stage window per driven tab; adopts a web view only when `webView.window == nil`; if the user is showing the tab, refuses rather than steal first responder. `ControlInput.swift`: named-key → keycode table. Schema: `click` + `button: left|right|middle`, `click_count` 1–3, `modifiers` ("cmd+shift"); new `hover(ref|coordinate)`, `drag(from ref|start_coordinate, to ref|coordinate)`; `key` + `repeat` (≤50); `scroll_to` covered by `scroll(ref)` (alias optional). Routing: click on `<select>`/color/date/file input → `form_input`/`file_upload` (native popups run a modal menu on screen). Right-click: cancel menu via `willOpenMenu` override in an app-side `WKWebView` subclass (`WebViewFactory` gets an injectable class); if unreliable per spike, synthesized `contextmenu`. HTML5 native DnD would start a real `NSDraggingSession` following the user's cursor — needs private API; use synthesized `DragEvent`s with `DataTransfer`; pointer-event drags use the trusted path.
Tests: headless param parsing; spike asserts promoted into LunaTests `ControlStageTests`: `testTrustedClickOnAgentTab`, `testUserViewingTabRefusesInput`, `testNoFocusOrWindowMoves`.

## Phase 4 — three parallel streams after P1 (M each)
4a `file_upload(ref, files:[{name, mimeType, data base64} | {path}])`: `DataTransfer` → `input.files` + input/change, or drop event for drop zones. Paths: `lstat` regular, no symlink (`O_NOFOLLOW`), `st_nlink == 1`, owned by current user, readable, 10 MB/file, 25 MB total; deny `~/.ssh`, Keychains, Luna's own data; path uploads always confirm unless allow-all. Check the socket's line size for big base64. Tests: headless `ControlUploadGuardTests` (`testHardLinkRefused`, `testSymlinkRefused`, `testOversizeRefused`, `testOtherOwnerRefused`); windowless `testUploadSetsFilesAndFiresChange`.
4b `network_read(pattern?, include_bodies?, clear?)`: document-start page-world `WKUserScript` on agent-touched tabs wrapping fetch/XHR/sendBeacon/WebSocket send; main/sub-frame document responses from `WKNavigationResponse` (status + all headers); others from `PerformanceObserver` resource timing. Bodies ≤10 KB each, ≤500 entries, all through the redactor. Can't capture (say so in the description): browser-added headers (Cookie, UA), Set-Cookie, CORS-hidden cross-origin response headers, no-cors bodies, worker/service-worker requests, image/script/CSS headers/bodies; the log is page-writable → untrusted. Tests: windowless `testFetchAndXHRCaptured`, `testAuthorizationHeaderRedacted`, `testBodyCapped`.
4c `batch(actions:[{tool, args}], max 20)`: each step through the gate; `"$N"` = first ref in step N's output; stop on first error; no nesting. Tests: headless `testStopsOnFirstError`, `testRefSubstitution`, `testEachStepGated`, `testNestedBatchRefused`.
