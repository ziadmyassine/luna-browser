# Code of conduct

Luna follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be kind, assume good intent, keep criticism about the work, and never
harass anyone — in issues, pull requests, reviews, or anywhere else the project
is discussed.

If someone breaks this, tell a maintainer privately (see [SECURITY.md](SECURITY.md)
for how to reach us without a public issue). The maintainers decide what happens,
up to banning someone from the project.
