# Security

## Reporting a problem

Please do not open a public issue for a security problem. Use **Report a
vulnerability** on the repository's
[Security tab](https://github.com/ziadmyassine/luna-browser/security) instead,
which only the maintainers can see. If that button is not there, open an issue
asking a maintainer to contact you, without any details of the problem.

Say what you found, how to reproduce it, and which version or commit of Luna you
used. We will reply within a week, and tell you when a fix is out.

## What counts

Anything in Luna's own code, for example:

- a web page reaching Luna's chrome, another Space's cookies, or another tab;
- an extension getting more than its granted permissions;
- Luna Control acting without the approval it should ask for;
- passwords or sync data exposed or stored unprotected;
- the updater accepting a build it should not.

A bug in WebKit itself belongs to Apple: report it at
[security.apple.com](https://security.apple.com).

## Supported versions

Luna has not had a release yet. Fixes go to `main`.
