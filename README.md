# Luna

A native macOS browser built on Apple's WebKit (`WKWebView`) — not Chromium, not Electron.
Vertical sidebar instead of a tab strip, Spaces instead of tab hoarding, one command bar for everything.

**Status: planning.** No code yet. [`TODO.md`](TODO.md) is the single source of truth for scope,
architecture decisions and task breakdown; [`todo-board.html`](todo-board.html) renders it as a board.

- **Target:** macOS 26+, Swift 6, AppKit shell + SwiftUI surfaces
- **Sync:** iCloud only — no accounts, no servers of ours
- **Telemetry:** none
- **Price:** free
